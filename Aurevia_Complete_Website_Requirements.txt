2. DESIGN DIRECTION
==================================================

Create a sophisticated, elegant, modern and highly responsive design.

Primary color palette:

- Midnight Navy: #071A2B
- Champagne Gold: #D6B56A
- Ivory: #F5F1E8
- White: #FFFFFF
- Soft Charcoal: #1C1C1C

Use Midnight Navy as the main dark background.
Use Champagne Gold for important accents, buttons, icons and subtle borders.
Use Ivory/White for clean content sections.

Typography:

- Elegant luxury serif font for major headings and brand name
- Clean modern sans-serif font for body text and navigation

The design should use:

- Large cinematic destination photography
- Subtle animations
- Smooth scrolling
- Elegant hover effects
- Glassmorphism only where appropriate
- Soft shadows
- Large whitespace
- Rounded but sophisticated UI elements
- Premium gold micro-interactions

Avoid:

- Excessive gradients
- Cartoon-style graphics
- Cheap-looking stock-template design
- Excessive emojis
- Overly bright colors
- Generic airplane/globe logo graphics
- Cluttered layouts

The website must look excellent on:

- Mobile
- Tablet
- Desktop
- Large screens

==================================================

Build the project with a modern production-ready architecture.

Frontend:
Use a modern React-based framework such as Next.js.

Styling:
Tailwind CSS or an equivalent modern styling system.

Backend:
Use a secure API/server architecture.

Database:
Use a reliable database such as PostgreSQL.

Authentication:
Secure admin authentication.

Images:
Use optimized image handling.

Forms:
Use robust client-side and server-side validation.

Architecture should be modular and scalable.
